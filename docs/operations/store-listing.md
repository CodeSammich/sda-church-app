## Fields and limits

| Field | App Store Connect | Google Play Console | Limit |
| --- | --- | --- | --- |
| Name | App Information → Name | Main store listing → App name | 30 |
| Subtitle | App Information → Subtitle | (none) | 30 |
| Short description | (none) | Main store listing → Short description | 80 |
| Promotional text | Version page → Promotional Text | (none) | 170 |
| Keywords | Version page → Keywords | (none) | 100 |
| Description | Version page → Description | Main store listing → Full description | 4,000 |
| What's new | Version page → What's New | Set automatically from the release PR's title | 4,000 / 500 |

In App Store Connect, add each language under **App Information → Localizable
Information**. In Play Console, use **Main store listing → Manage translations**.
English (United States) is the primary language in both.

App Store Connect copies the English name into a new language as a placeholder; replace
it with that language's name. If saving a language reports that "the app name you entered
is already being used", reload the page before trying another name. Once a language
saves, the page doesn't refresh, so the next **Save** tries to create the language again
and trips over the app's own name. After a reload the name is usually already there.

```text
No sign-in is required; every feature works without an account.

This is the official app of the New York Chinese Seventh-day Adventist Church. It shows the church's weekly bulletin, which comes from the church's own server, and reads Bible text and audio from public Bible services.
```

  it and run it in iPhone mode. The current set comes from the key screens of the

  (9:41, full battery and signal); see [Key screens](native-builds.md#key-screens).

## What not to claim

- **Offline reading:** the Bible needs a connection; chapters load over the network.
- **Whole-Bible search:** search covers the current chapter only.
- **Audio for every translation:** audio is available for CUV, CUVS, BSB, and RVR 1909,
  not KJV. The descriptions' "other languages" means Spanish for now.
- **Hymn lyrics, sheet music, books, or lessons in the app:** they open on their
  publishers' websites.
- **Notifications or widgets:** the app has neither.
- **A location-based Sabbath time:** the countdown is for New York.
- **A kids app:** don't use "for kids" or "for children" in the name, subtitle,
  screenshots, or description; see the audit's item 4.
