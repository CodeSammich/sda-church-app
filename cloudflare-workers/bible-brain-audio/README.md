# Bible Brain audio Worker

The church's private proxy for Faith Comes By Hearing's Bible Brain API, which keeps
the API key out of the app and gives it Cantonese Bible audio (#241).

Setup, cost, deployment, and the checks before turning it on are in
[Cantonese Bible audio](../../docs/operations/bible-brain-audio.md). The license terms
it follows are in [LEGAL.md](../../docs/LEGAL.md).
